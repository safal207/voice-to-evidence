# Snapshot output

The Snapshot is a Markdown document with a fixed section structure. It is a
**draft artifact for human safety review**, not a verdict.

## Sections

1. **Title** — `# Agent Action Audit Snapshot — <incident_id>`
2. **Disclaimer** — one-line note that the artifact is a draft for human
   review.
3. **Incident metadata** — incident id, agent, workflow, optional reporter,
   optional `occurred_at`.
4. **Action** — what the agent did.
5. **Permission boundary** — the policy the agent was operating under.
6. **Evidence available before action** — list, or `_(none recorded)_`.
7. **Missing evidence** — list, or `_(none flagged)_`.
8. **Reversibility risks** — list, or `_(none flagged)_`.
9. **Original transcript** — present only if `transcript` was provided.
10. **Notes** — present only if `notes` was provided.
11. **Review** — recommendation block (`ALLOW` / `BLOCK` / `ESCALATE`), or a
    placeholder if not yet decided.
12. **Footer** — explicit note that the Snapshot does not constitute
    compliance certification, legal advice, or production sign-off.

## Determinism

Given the same `IntakeRecord`, `render_snapshot` always produces the same
Markdown. There is no LLM, randomness, or network call in the render path.

## Example

Input: [`examples/intake_example.json`](../examples/intake_example.json).

Excerpt of output:

```markdown
# Agent Action Audit Snapshot — VTE-2026-0001

> Draft artifact generated by voice-to-evidence.
> Intended for **human safety review**, not autonomous sign-off.

## Incident metadata
- **Incident ID:** VTE-2026-0001
- **Agent:** support-triage-agent
- **Workflow:** customer_refund_processing
- **Reporter:** ops-engineer-amy
- **Occurred at:** 2026-05-07T14:22:00Z

## Action
Agent issued a $480 refund to the customer's card on file directly, without
prior human approval.

## Permission boundary
Agent is permitted to draft and recommend refunds up to $100; refunds above
that require human approval in the support console.

## Missing evidence
- Order history lookup confirming purchase amount
- Approval record from human reviewer
- Fraud-signal check for the customer account

## Review
**Recommendation (draft):** `ESCALATE`
```
